# Frontend maintenance

## Recurring cadence

- Weekly: review frontend errors, accessibility regressions, performance budgets,
  browser support, and generated-client drift.
- Monthly: review supported backend API and report-schema releases, wallet and
  localization fixture demand, and ownership rotation.
- At every backend retirement: remove the compatibility fixture only after the
  documented retirement date and release notes are published.

## Ownership

The frontend maintainers own the calendar, compatibility matrix, release
rollback procedure, and pilot feedback queue. Each review records evidence and
an accountable owner.
